## Deliberate boundaries

These changes provide readback, retention, validation and adapter code. They do not manufacture an observation from a real GPU, establish model-domain quality, prove hidden server internals, or create physical evidence. The frozen GR00T interface exposes a reset response but no independent internal-cache readback; that limitation is recorded rather than claimed away. Missing native channels are explicit and cannot authorize a qualified comparison.

The exact-workcell adapter requires explicit native apply/read handlers for admitted dimensions. It does not infer a physical API from a label or silently ignore unsupported dimensions. Its full-schedule collector remains distinct from the ten-cell internal diagnostic dispatcher. No new evaluation or blanket qualification bypass was introduced.

Registered candidate IDs are now preserved in scientific publication, and interface selection is explicit. Adding a new model/checkpoint still requires its own admitted runtime/provisioning interface; this work neither invents candidates nor removes checkpoint/right/runtime admission.

The Website owner's active work was left untouched. The already-committed consumer fix was verified read-only; no TypeScript patch was duplicated or merged into that lane.
