# Controlled native policy execution

ADP-011/day 7 admission; ADP-050/day 28 execution and delivery. Owner: Nijel Hunt.
The missing boundary was a configured native simulator and independently scored
outcome behind the admitted agent queue.

`BLUEPRINT_CONTROLLED_NATIVE_REGISTRY` names an operator-owned, digest-bound
registry. Profiles bind one capture root, task, scenario and allowed team list
to immutable native packet/runtime source receipts, the policy interface and
canonical paid-attempt authority inputs. Request JSON cannot choose native
files, source modules, commands or paid resource limits.

The controlled worker currently executes approved HTTPS policies on the sealed
Franka rigid task. Container/controller/model profiles require a separately
qualified sandbox factory; the provider worker refuses them when no such factory
is configured. Do not publish those profiles as runnable merely because their
registration or component proof exists.

The simulator supplies approved camera PNGs and robot state, executes bounded
joint/gripper actions, records native samples after each motor step, and invokes
Blueprint's deterministic scorer. Scored task failure is a completed evaluation;
missing/undecidable outcome evidence is not. Development scope never grants
qualification, physical success or public claim upgrades.

The queue creates one exclusive launch intent per admitted job. Interrupted jobs
can reopen sealed allocator output but cannot allocate again. Unknown provider
state retains the funded hold. A failed attempt reports blocked only after fresh
provider-zero evidence. Independent paid-admission/watchdog/teardown gates remain
in the canonical allocator; the dispatcher permits their bounded wall time.

A protected operator credential file may supply a job/endpoint-bound API bearer
credential. Only its private bound runtime input reaches the trusted simulator;
it is not included in customer observations, source control or public receipts.
Credential expiry/revocation remains required during run closeout.

Before paid execution: validate the service user's asset traversal permissions,
frozen configuration, bundle/import closure, exact deployed release, spend
reconciliation, API-origin approval and fresh provider zero. The live completion
artifact is a new policy/run receipt and its team-only production result readback.

The admitted agent dispatcher runs from the atomically promoted immutable release,
using the task-evaluation identity keys rather than the archived build-checkout
keys in the shared credential environment. Controlled requests always stage in
the native inbox; missing registry/profile bindings block there instead of
falling back to the legacy executor. Its independent hard-TTL watchdog survives
caller exit, while the existing cgroup reconciler reaps other descendants.
