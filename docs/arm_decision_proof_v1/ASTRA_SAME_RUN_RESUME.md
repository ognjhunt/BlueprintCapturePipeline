# Astra same-run resume

This is an ADP-009 construction-rehearsal dependency. It does not authorize a
new provider allocation, increase an owner budget, or qualify physical truth.

The production component automatically selects the latest retained Astra
runtime in the same stage output. The retained artifact contract binds the
exact request, source/rights receipt, configuration, CAD source archives, phase
bytes, and complete inference journal. Unknown calls fail closed. Completed
CAD exports and Blender outputs are verified and reused; completed model
outputs retain their original response evidence. Visual round numbers and
reserved inference costs are never reset.

New Astra stage chains persist immutable completion checkpoints. Restarting
the same run/root with the same envelope, configuration bytes, and deadline
adopts the completed prefix and resumes Astra in a new subdirectory. Original
producer logs and runtime artifacts remain retained. Historical stage roots
without these checkpoints and partial CAD states without an authenticated
completed boundary are refused rather than inferred complete.

For a no-cost packaging replay of fully completed authoring:

```bash
python -m blueprint_pipeline.task_evaluation_astra_authoring_replay \
  --retained-stage-root /path/to/retained/producer \
  --replay-root /path/to/new/scratch \
  --toolchain-root /path/to/sealed/toolchain \
  --component-root /path/to/sealed/toolchain/component
```

This command refuses incomplete authoring and does not enter the model, CAD,
Blender, or external-cost execution paths. Packaging still performs its existing
deterministic checks and produces a candidate pending qualification.

The separate frozen `task_evaluation_retained_astra_scene_preparation.v1`
schema interprets historical Astra quotes without changing the legacy retained
schema or granting new execution/spend authority.
