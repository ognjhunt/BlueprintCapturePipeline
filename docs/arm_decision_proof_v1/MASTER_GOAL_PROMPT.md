## ADP-009B — Synthetic Removal, Inpainting, And USD Replacement

On one exact rights-admitted matched InteriorGS/SAGE scene:

1. Verify scene identity, units, axes, transforms, semantics, and collision pair.
2. Select one rigid source object and exact collision body.
3. Partition every Gaussian exactly once into background, object, or uncertain.
4. Remove/deactivate both source-object appearance and collision.
5. Freeze collision-aware calibration and test trajectories; render
   object-present RGB from the publisher splat and bind the exact cameras as
   synthetic method inputs. These are self-consistency inputs, never independent
   observation evidence. Keep external metric depth separate as a validation
   oracle unless an admitted method explicitly accepts it and that substitution is
   preregistered. SAGE collision depth is not measurement-authoritative surface
   truth. Keep all clean-background truth inaccessible until the result is
   sealed.
6. Run Inpaint360GS unchanged on author data only. Run InFusion with its
   method-native incomplete-splat depth through the verified
   depth/c2w/intrinsics-to-supplemental-Ply and explicit
   original-Ply-composition adapter. Run AuraFusion360 through its separate
   representation/checkpoint adapter as the quality challenger.
7. Preserve the unedited base and create a new immutable edit version.
8. Insert one exact digest-bound SimReady USD at the prescribed pose/contact.
9. Bind visual mesh, collider, dimensions, mass, center of mass, inertia,
   friction, restitution, material, semantic identity, and reset.
10. Qualify the composed stage in Isaac.
11. Compare the known-good manual USD against deterministic parametric geometry
    plus NVIDIA USD Content Agents; include SimReadyGen only if separately
    admitted. VLM output never becomes geometry or physics authority.

Tests use frozen object-present test trajectories only for outside-mask edit
locality, boundary halos, floaters, ghost objects, cross-view consistency, and blinded
hidden-region review. Full-reference RGB/depth inside the hole is used only when
clean background truth exists. Asset tests cover CAD-to-USD geometry
preservation, visual/collider distance, support gap,
penetration, contact normals, deterministic drop/settle, slide/tip, and gripper
approach/contact/close/lift/release.

Day-14 terminal: the source object is absent exactly once from appearance and
physics, the replacement exists exactly once, all transforms round-trip, and
the complete case replays inside preregistered task-derived tolerances.
