# Website preparation outcome handoff

ADP-009D/day-28 typed-abstention and delivery precursor, also serving beta
journey L3/L6. The fresh office-video run is development-only; this change
does not complete sealed public-scene qualification or physical trials.

The existing signed `website-preparation-status` route negotiates v3 when the
WebApp asks for version 3 or later. V1 and v2 readers retain their exact shapes.
V3 seals a required-nullable `outcome` with the usual current-source, capture,
rights, owner, task-context and ledger checks. Its acceptance names v3 so the
durable wake-up's postflight rereads the same receipt version.

`website_preparation_outcome.py` reads the existing handoff, preparation,
runtime/collision and robot verdict chain. Every reference stays inside the
capture, refuses symlinks/traversal, and verifies canonical digests. The task
context and preparation/collision identities must agree. No provider call,
new retry, allocation or task/owner acceptance is performed.

A rejected bounded carry search is `robot_incompatibility` with the mandatory
`conservative_configuration_check` basis. It does not prove mechanical
impossibility for every grasp/station/robot, and its scene scale remains an
estimate. A missing station or allowlisted missing task evidence is
`insufficient_evidence`. Unknown exceptions never become hardware exclusions.
Active attempts, handed-off work and ended authority cannot inherit a previous
attempt's conservative finding through this reader.

The WebApp accepts v3 before the Pipeline deploys it, keeps v1/v2 readable, and
maps these findings to one status used by the signed owner page and workspace.
It separately reads the existing verified Atlas failure receipt to close out
reconstruction failures already retained in production. Such a failure is a
Blueprint processing issue, never a robot verdict. The exact floor-ball
reconciliation refusal is a WebApp regression fixture.

Verification: preparation status/terminal/outcome tests cover real birth/lease
and signed-source checks, wrong context/robot/collision, tampered or escaped
references, missing station evidence, and additive negotiation/acceptance.
Policy workers, allocator admission, watchdog, teardown and driver contracts
are unchanged; no paid evaluation is launched to test this reporting seam.
