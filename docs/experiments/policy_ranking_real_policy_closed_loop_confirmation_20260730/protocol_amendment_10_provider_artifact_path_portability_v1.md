# Protocol Amendment 10: Provider Artifact-Path Portability

Frozen prospectively: 2026-07-30T12:54:44-0500

## Defect identified before WAM output

The direct provider result used absolute paths from the temporary GPU instance.
Those paths would not resolve after the output ZIP was downloaded and extracted
locally, even though all PNG and MP4 bytes were present. No current-reference
WAM output existed when this handoff defect was identified.

## Prospective correction

Provider runtime results now record every generated PNG and MP4 path relative to
the result root. Relative paths may not be absolute, contain `..`, escape the
extraction root, resolve to symlinks, or reference missing or empty files. The
model-neutral WAM result validator requires an explicit extraction root for a
portable result, rebases every path, verifies every recorded hash, and returns
normalized absolute local paths to the closed-loop harness.

In-process WAM runners retain their existing absolute-path behavior. This is a
provider transport correction only; generated bytes, model inputs, inference,
thresholds, controls, budgets, and claim gates are unchanged.

## Claim boundary

Successful rebasing proves artifact portability and integrity, not WAM
causality, reliability, episode coherence, ranking, physical success, transfer,
economics, or the thesis.
