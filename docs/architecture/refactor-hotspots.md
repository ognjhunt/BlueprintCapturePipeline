modules that a future agent should split carefully. Do not refactor these just
because they are large; split only when tests and contracts make the boundary
clear.

## Refactor Rules

- Preserve raw capture truth and canonical package truth before moving code.
- Keep fallback geometry, raw bypass, mocked payments, missing SDK env, and
  automated gates labeled as blockers or snapshots where appropriate.
- Add or run targeted tests before each split.
- Prefer extracting pure builders first. Move I/O, network calls, shell commands,
  and provider clients only after behavior is pinned by tests.
