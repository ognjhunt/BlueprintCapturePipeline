# Documentation Archive

This directory contains superseded point-in-time audits, completed handoffs,
historical goals, and implementation snapshots. These records are retained for
provenance; they are not current product doctrine or operator runbooks.

Current doctrine starts at `PLATFORM_CONTEXT.md` and
`WORLD_MODEL_STRATEGY_CONTEXT.md`. Current operational instructions remain under
`docs/runbooks/` and current contracts remain in their established paths.

The SC3 quality-gap ledger dated 2026-07-09 remains outside this archive until
that launch ledger closes.
